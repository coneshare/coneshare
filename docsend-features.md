# Secure File Sharing

DocSend provides secure file sharing that allows you to control every aspect of your shared files, even after you hit send.

## Key Capabilities

### Link-Based Sharing
Instead of using email attachments, DocSend allows you to share documents through secure links. This provides a seamless viewing experience that supports all major file formats. You can share multiple links in seconds or send personalized file requests.

### Granular Access Control
You retain full control over sensitive documents. Key security features include:
- **Passcodes:** Protect your links with a password.
- **Email Verification:** Ensure only specific individuals can access the file.
- **Download Restrictions:** Turn on or off the ability for recipients to download the file.
- **Expiration Dates:** Set links to expire after a certain period.

### Live Document Updates
If you need to fix a typo or update a document, you can replace the file in DocSend, and all previously shared links will automatically point to the new version. This ensures everyone is always on the same page.

# Dynamic Watermarking

## Key Capabilities

### Smart Protection
- Enhance watermark effectiveness by automatically displaying the viewer's information, such as their email, IP address, and the date and time of viewing.

### Full Customization
- Add custom text and change the color, position, and rotation of the watermark for full control over its appearance.
- Apply digital watermarks to PDFs, Keynotes, Powerpoint presentations, and Word documents.

### Bulk Watermarking in Spaces
- When sharing multiple documents, you can upload them to a DocSend Space to apply a dynamic watermark to all of them at once and share them via a single link.
