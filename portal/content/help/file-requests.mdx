File Requests give clients, vendors, and candidates a clean upload page that deposits submissions straight into your chosen Coneshare folder—avoiding email size limits and ad-hoc transfer links.

## Creating a File Request Link

1. Pick or create the **destination folder** where incoming submissions should be stored.
2. Create a **File Request** link and configure optional title, instructions, password, or expiration window.
3. Share the upload link with external contributors or embed it into your client portal.
4. Review submitted files directly inside your target folder along with uploader metadata and timestamps.

## Embedding into Client Portals

If your organization self-hosts Coneshare behind Nginx and wants to embed File Request upload pages inside an external portal via iframe, see [File Request Embedding](/features/file-request-embed) and the [Server Admin Embedding Guide](https://docs.coneshare.com/en/file-request-embedding/).
