Coneshare helps teams see what happens after a link is sent and lets you interact with your workspace directly from AI assistants via Model Context Protocol (MCP).

## Reading Engagement Analytics

- **Page-by-page dwell time:** See how long visitors spent on each slide or page, plus completion rate across the full document.
- **Visitor session logs:** Inspect verified emails, timestamps, device/browser info, and folder navigation history across datarooms.
- **Link clicks &amp; video telemetry:** Track clicks on embedded URLs as well as video watch duration and scrubbing behavior.
- **Real-time alerts:** Receive email, Slack, or webhook notifications when key links are opened or revisited.

## Connecting ChatGPT, Gemini, and Claude (MCP)

Use Coneshare&apos;s Remote MCP connector to search documents, create or update share links, manage dataroom content, and query engagement analytics directly inside ChatGPT, Gemini, or Claude:

1. Visit the [Agents &amp; MCP overview](/agents) for supported workflows and OAuth connection instructions.
2. Authorize your workspace using your Coneshare account (OAuth 2.1) or an API key.
3. Ask your assistant to summarize recent view sessions, locate files, or generate a new share link.

> Server administrators configuring `SITE_DOMAIN` and reverse proxy rules for MCP can follow the [Remote MCP Server Admin Guide](https://docs.coneshare.com/en/mcp-server/).
