Coneshare 帮助团队在不打乱现有存储习惯的前提下，为对外文档分发和协作加上细粒度的权限管控、动态水印与阅读洞察。

## 核心概念一览

| 功能空间 | 适用场景 | 核心能力 |
| :--- | :--- | :--- |
| **个人文档库** | 整理个人/日常材料与单个文档外发 | 多级目录、单文件安全链接、版本更新 |
| **虚拟资料室 (VDR)** | 融资尽调、项目交付、对外合作门户 | 自定义 Banner、按链接配置文件夹可见性、Q&A 与打包下载 |
| **文件收集 (File Request)** | 向客户或外部供应商收取大文件 | 独立上传页面、密码/有效期限制、投递审计记录 |

## 推荐上手流程

1. **上传或导入文档**：直接上传 PDF、PPT、表格或视频，或对接 [Google Drive](/integrations/google-drive)、[Dropbox](/integrations/dropbox)、[Nextcloud](/integrations/nextcloud) 导入。
2. **选择分发形式**：发送单个文档可使用安全分享链接；需要整理多份材料与目录结构时，建议创建 [虚拟资料室](/zh/help/datarooms)。
3. **配置安全规则**：按不同接收方需求设置访问密码、邮箱验证、过期时间、禁止下载及 [防拍照动态水印](/zh/help/dynamic-watermarking)。
4. **查看阅读反馈**：通过访客会话日志、逐页停留时长与实时通知，及时掌握对方关注重点。

> 如需查阅 Docker 安装步骤或 `app.env` 服务器配置，请前往 [服务器管理员手册](https://docs.coneshare.com/en/quick-start/)。
